A VISION of the final version of this project 
Current system is NOT aware of strategies or multiple tasks
-----------------------------------------------------------

Hierarchy in a problem solving process:

Strategy

	Task 1
		RuleContainer 1
		RuleContainer 2

	Task 2
		RuleContainer 6

	Task 3
		RuleContainer 4
		RuleContainer 5
		RuleContainer 3


On strategy level --the most abstract level-- we can dynamically create a task
and place it in the task list at a destined position. The task can be assigned one or more rule containers.

Currently, the order of tasks, rule containers and rules withing a container are defined by how they are stored in files.
Actually there are no separate tasks yet in the current version of the project.

The future strategy level is supposed to be optional and can be used to reorder tasks and containers as the need arises 
to dynamically change the execution path of a problem solving process.
